# Data

Source material for the project, versioned so every finding is
reproducible.

## Present

Nothing yet. Unlike the sibling Voynich project, which had an
already-agreed canonical transcription to import on day one, and even more
starkly than the sibling Rongorongo project (whose corpus is at least
physically extant), Oak Island's primary artifact — the 90-foot stone — is
physically lost. There is no canonical source to select from at all yet;
there are only competing secondhand renderings whose reliability has not
been assessed. See `config/sidequests.md` SQ-1 and SQ-2.

## Needed

- **Provenance timeline** — the sourced, trust-tiered record of every
  claim about the stone, its inscription, and its reported decoding,
  produced by SQ-1. This is the actual first "data" this project needs,
  before any transcription work.
- **Symbol-transcription catalogue** — every known published rendering of
  the stone's symbols, with source, publication date, and trust tier,
  produced by SQ-2. Not yet selected or assessed.
- **Comparative fabrication-benchmark panel** — documented, confirmed
  fabricated or embellished treasure-cipher cases for SQ-4, gathered as a
  calibration set, not bulk-loaded up front.
- **Reference/comparator corpora** — for the Linguist to compare claimed
  plaintext against period-appropriate English usage. To be added as
  specific hypotheses are tested, not bulk-loaded up front.

## Convention

Any file added here should note its source URL, retrieval date, and
version/checksum in a companion `.source.md` (or in this README) so
provenance is never lost. Do not bulk-download candidate sources without
explicit user authorization — this is a standing rule across all three
sibling projects.
